## 功能特点

- **价格计算器**：快速计算拼单价和单买价，包含平台手续费
- **批量分析**：批量处理多规格商品的价格计算
- **现代UI**：基于 Ant Design Pro 的专业界面
- **响应式设计**：适配电脑和移动设备
- **数据即时处理**：所有计算在本地完成，无需服务器

## 设计风格

本项目界面以 Ant Design 的现代极简风格为主，整体采用黑白灰色调，去除品牌色和趣味化元素，突出系统工具的专业感和高效感：

- 主色调为黑、白、灰，弱化彩色元素，整体冷静克制
- 所有内容模块采用极简卡片布局，分区用细分割线和留白区分
- 按钮、表单、表格等组件均采用黑白灰配色，动效克制，反馈直接
- 字体、图标均为线性风格，避免彩色和卡通化
- 参考 Ant Design 官网、Ant Design Pro、Notion、Linear 等极简后台系统风格

### 设计风格规则

#### 1. 色彩与主题
- 仅使用黑、白、灰三色为主色调，避免使用高饱和度色彩。
- 主要按钮、重要信息可用深灰或黑色，次要操作用浅灰。
- 禁止使用品牌色、红色、黄色、绿色等高亮色，除非用于极少数警告/成功提示。
- 背景色建议为纯白（#fff）或浅灰（#f5f5f5），分区可用更深灰（#f0f0f0、#e5e5e5）。

#### 2. 布局与间距
- 所有页面、卡片、表单、表格等组件，外部留白不少于24px，内部间距不少于16px。
- 卡片、表单、表格等采用圆角（4px-8px），阴影极浅或无阴影，仅用细边框分隔。
- 分区、模块之间用1px浅灰分割线，避免厚重分隔。

#### 3. 组件规范
- 按钮：主按钮用黑色/深灰，次按钮用灰色描边，禁用状态用浅灰填充。
- 输入框、下拉框、选择器等表单组件，边框为浅灰，聚焦时变深灰或黑色。
- 表格：表头深灰，表体白色或浅灰，选中行用浅灰高亮，无多余线条。
- 弹窗、抽屉、通知等浮层，背景白色，阴影极浅，内容居中。

#### 4. 字体与图标
- 字体采用系统默认或 Ant Design 推荐字体，字号14px-16px，标题加粗。
- 图标仅用线性风格（Outlined），不使用彩色或填充图标。
- 禁止使用卡通、拟物、品牌相关图标。

#### 5. 动效与反馈
- 动效克制，按钮、切换、加载等仅有平滑过渡，无夸张动画。
- 加载、提示、弹窗等反馈信息仅用黑白灰色系，信息明确直接。
- 错误、警告、成功等状态提示，颜色饱和度降低，避免刺眼。

#### 6. 响应式与适配
- 移动端按钮、输入框高度增加，保证触控友好。
- 卡片、表格等在小屏幕自动堆叠，内容不溢出。
- 所有字体、间距、组件尺寸均需适配不同屏幕。

#### 7. 其他
- 禁止使用任何拼多多、品牌、趣味化、装饰性元素。
- 所有内容、功能以高效、专业、极简为核心，减少视觉干扰。

## 技术栈

- **前端框架**：React 18 + TypeScript
- **UI组件**：Ant Design 5.x（以黑白灰极简风格为主，突出系统工具感）
- **样式方案**：Less
- **状态管理**：Zustand
- **路由管理**：React Router 6
- **构建工具**：Vite

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务
npm run dev

# 构建生产版本
npm run build
```

## 部署

这个项目配置为静态网站，可以轻松部署到任何静态托管服务，如 Netlify、Vercel、GitHub Pages 等。

### Netlify 部署步骤

1. 在 Netlify 上创建新站点
2. 关联你的 Git 仓库
3. 设置构建命令为 `npm run build`
4. 设置发布目录为 `dist`
5. 点击部署按钮
